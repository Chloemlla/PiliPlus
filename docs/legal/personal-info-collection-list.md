# PiliPlus 个人信息收集清单

更新日期：2026-08-07

以下为本应用收集、使用个人信息的清单，供你了解各类信息的使用情况。

| 信息类型 | 收集方式 | 用途 | 是否共享 |
| --- | --- | --- | --- |
| Bilibili 登录凭据（Cookie/令牌） | 用户主动授权 | 维持登录态、调用 Bilibili 接口 | 仅在你与 Bilibili 之间 |
| 设备与网络信息（型号、系统版本、网络状态） | 应用自动 | 正常调用 Bilibili 接口、适配网络 | 仅在你与 Bilibili 之间 |
| 应用设置与使用数据（设置、搜索历史、观看记录） | 应用自动 | 本地功能与个性化 | 不共享 |
| 下载内容与图片缓存 | 应用自动 | 离线播放与性能优化 | 不共享 |
| 你主动选择的媒体文件（头像、封面） | 用户主动选择 | 上传至 Bilibili 相应功能 | 仅在你与 Bilibili 之间 |

## 说明

1. 除上表列明的用途外，本应用不收集、不分析其他个人信息。
2. 开发者不运营服务器，上述信息主要存储在你的设备本地。
3. 你可以随时在「应用声明 → 法律信息」中撤回同意，或清除本地缓存与数据。
